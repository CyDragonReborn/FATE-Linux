WTRerunProgramUtility Program

AUM: Application Update Manager (2!)

About the WTRerunProgramUtility Progam

This utility program is shipped with each game that needs to update itself. It takes in, through some environment variables, a list of commands to run; the commands include
CommandExplanation
DdirectorySets the default directory for subsequent commands
PWprogramruns a program and waits for the result
PIprogramruns a program and keeps going
Wpid maxtimewaits until process pid has exited, for a maximum time of maxtime milliseconds

This program is used by, e.g., the CUpdateMgr::Bounce method

The sample directory contains samples of commands and shows how you can set environment variables from a batch (.bat) file to test out your commands.
